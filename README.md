# Ressource CUA — Les Pays-Bas face au changement climatique

Étude de cas interactive de géographie pour la classe de seconde.

La ressource propose un parcours d’étayage inspiré de la conception universelle des apprentissages (CUA) :

- deux profils de médiation : élève allophone B1 anglophone et élève francophone en difficulté de compréhension ;
- analyse de la production réelle de l’élève ;
- indices progressifs et ciblés ;
- réponses attendues accessibles après une première tentative ;
- progression enregistrée localement sur l’appareil ;
- fonctionnement sans clé API.
